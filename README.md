# pjm-queue-data

A clean, reproducible table of every generation interconnection request in PJM's public queue, and the statistics
Certified Interconnection is built on. Part of [Certified Interconnection](https://github.com/certified-interconnection).

## What's in it
- `data/pjm_generation_requests.csv`: one row per generation interconnection request (8,190 rows): project id,
  queue window, status, state, county, transmission owner, MW, fuel, submitted / withdrawn / in-service dates.
- `results/pjm_queue_stats.json`: the statistics below, regenerated by `pjm_queue.py`.

## Headline numbers (snapshot downloaded Nov 24, 2026)
| | |
|---|---|
| Generation requests in the file | 8,190 |
| Submitted 2008 to 2017 that reached service | 24% of requests (40% of MW) |
| Submitted 2008 to 2017 that withdrew | 72% |
| Active requests | 2,347 (360 GW) |
| Active requests sharing their county with 5+ other active requests | 68% |
| Active MW in counties with 5+ requests | 78% |
| Median active request | 100 MW |

The crowding is why projects are studied as clusters: most new requests land next to other new requests and load
the same lines.

## Reproduce
```bash
python fetch.py       # downloads PlanningQueues.xml from pjm.com
python pjm_queue.py   # writes the CSV and results/pjm_queue_stats.json
```

## Source and limits
Data is PJM's public `PlanningQueues.xml`. This file covers queue status, not the power-system model: PJM's network
cases are Critical Energy Infrastructure Information and are not public, so grid studies in Certified
Interconnection run on public synthetic grids with these real request sizes. Completion rates are computed for
2008-2017 submissions so that most requests have had time to resolve.
